Introdução ao Flexbox

⬅ Voltar ao Hub

O que é Flexbox?

Flexbox é um recurso do CSS usado para organizar elementos em uma direção: em linha ou em coluna. Ele ajuda a alinhar itens e distribuir o espaço entre eles.

O elemento que recebe display: flex é o contêiner. Os elementos que estão dentro dele são os itens.

Eixo principal e eixo transversal

O Flexbox trabalha com dois eixos. A direção escolhida em flex-direction define o eixo principal. O outro eixo é chamado de transversal.

  • Com flex-direction: row, os itens ficam em uma linha.
  • Com flex-direction: column, os itens ficam em uma coluna.
  • justify-content organiza os itens no eixo principal.
  • align-items alinha os itens no eixo transversal.

Exemplo de alinhamento

Abaixo, os itens estão centralizados e têm o mesmo espaço entre si.

HTML
CSS
Flexbox
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 16px;
}

Propriedades importantes

  • flex-direction: escolhe a direção dos itens, como linha ou coluna.
  • justify-content: distribui os itens no eixo principal. Pode usar valores como center e space-between.
  • align-items: alinha os itens no eixo transversal.
  • gap: define o espaço entre os itens.
  • flex-wrap: permite que os itens passem para outra linha quando não cabe tudo.
.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

Tamanho dos itens

Também podemos controlar como cada item ocupa o espaço disponível:

  • flex-grow controla o quanto o item pode crescer.
  • flex-shrink controla o quanto ele pode diminuir.
  • flex-basis define um tamanho inicial para o item.

A forma abreviada flex: 1 1 150px; combina essas três propriedades.

.card {
  flex: 1 1 150px;
}

Onde podemos usar?

Flexbox é útil em menus, barras de navegação, grupos de botões e linhas de cartões. Ele funciona bem quando precisamos organizar os itens em uma direção.

Quando o layout precisa controlar linhas e colunas ao mesmo tempo, o CSS Grid pode ser uma opção melhor.
