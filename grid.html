O que é CSS Grid?

CSS Grid é um recurso para organizar os elementos em linhas e colunas. Diferente do Flexbox, que trabalha em uma direção por vez, o Grid permite cuidar das duas dimensões ao mesmo tempo.

O elemento com display: grid é o contêiner, e os elementos dentro dele são os itens da grade.

Criando uma grade

Usamos grid-template-columns para definir as colunas e grid-template-rows para definir as linhas. A unidade fr divide o espaço disponível entre as colunas.

.grade {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Nesse exemplo, repeat(3, 1fr) cria três colunas do mesmo tamanho. O gap define o espaço entre elas.

Posicionando os itens

Um item pode ocupar mais de uma coluna ou linha. Para isso, usamos propriedades como grid-column e grid-row.

.destaque {
  grid-column: span 2;
}

O valor span 2 faz o item ocupar duas colunas. Também é possível indicar as linhas de início e fim.

.conteudo {
  grid-column: 2 / 4;
  grid-row: 1 / 3;
}

Áreas do Grid

Com grid-template-areas, podemos dar nomes às partes do layout e indicar onde cada elemento deve aparecer.

.pagina {
  display: grid;
  grid-template-areas:
    "topo topo"
    "menu conteudo"
    "rodape rodape";
  grid-template-columns: 200px 1fr;
  gap: 12px;
}

header { grid-area: topo; }
nav    { grid-area: menu; }
main   { grid-area: conteudo; }
footer { grid-area: rodape; }

Deixando a grade responsiva

Podemos usar minmax() para definir um tamanho mínimo e máximo para as colunas. Com auto-fit, a grade tenta encaixar a quantidade de colunas que cabe na tela.

Layout
.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 16px;
}

Grid ou Flexbox?

Grid é uma boa escolha para montar estruturas com linhas e colunas, como uma página inteira ou uma galeria. Flexbox costuma ser mais simples para alinhar itens em uma única linha ou coluna.

Também podemos usar os dois juntos: Grid organiza as áreas da página e Flexbox alinha os itens dentro delas.
